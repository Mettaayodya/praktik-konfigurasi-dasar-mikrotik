# Praktik Konfigurasi Dasar MikroTik

Repositori ini berisi dokumentasi praktikum mandiri untuk mempelajari dasar-dasar konfigurasi jaringan menggunakan MikroTik. Setiap lab mencakup tujuan praktikum, tahapan konfigurasi, pengujian, serta hasil dan analisis.

Praktikum dilakukan secara bertahap menggunakan MikroTik hAP lite RB941-2nD, laptop Windows, dan hotspot ponsel sebagai sumber koneksi internet.

## Tujuan Pembelajaran

- Memahami konfigurasi dasar jaringan pada MikroTik.
- Mempelajari pengelolaan IP address, DHCP, DNS, dan NAT.
- Melakukan pengujian konektivitas jaringan.
- Melatih kemampuan troubleshooting berdasarkan hasil pengujian.
- Mendokumentasikan konfigurasi dan hasil praktikum sebagai portofolio pembelajaran administrasi jaringan.

## Perangkat dan Tools

| Komponen | Keterangan |
|---|---|
| Router | MikroTik hAP lite RB941-2nD |
| Komputer klien | Laptop Windows |
| Aplikasi konfigurasi | WinBox |
| Command-line tools | Windows CMD |
| Koneksi WAN | Hotspot ponsel |

## Metode Pengujian

Pengujian dilakukan menggunakan fitur diagnostik MikroTik dan perintah pada Windows CMD, sesuai kebutuhan setiap praktikum. Hasil pengujian digunakan untuk memverifikasi konfigurasi serta mengidentifikasi kendala yang ditemukan.

## Catatan

Repositori ini merupakan dokumentasi pembelajaran mandiri. Konfigurasi dan hasil yang dicantumkan didasarkan pada praktikum yang telah dilakukan, bukan simulasi seluruh fitur MikroTik.

Materi akan diperbarui seiring bertambahnya praktikum dan pemahaman mengenai administrasi jaringan.
